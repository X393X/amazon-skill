# Static Publishing Examples

Publishing is optional. The default delivery is the ZIP package generated by `scripts/package_report.py`.

## Public-safe Only

Allowed only when `privacy_mode` is `public_safe_real_world` or `strict_anonymized`, validator passes, privacy scan passes, and the report contains no private-internal data.

- GitHub Pages
- Cloudflare Pages
- Vercel
- other public static hosting

When public-safe publishing succeeds, set:

```json
{
  "publish_status": "public_safe_published",
  "shareable_url_scope": "public_safe"
}
```

## Internal Only

Allowed only when the user explicitly configures an internal target.

- Feishu document with restricted access
- enterprise intranet static server
- private object-storage link
- controlled internal document system

When internal publishing succeeds, set:

```json
{
  "publish_status": "internal_published",
  "shareable_url_scope": "internal_only"
}
```

## Not Allowed

- Do not publish `private_internal` reports to public static sites.
- Do not commit generated `dist`, `runtime`, `tmp`, raw Sorftime responses, or private config files.
- Do not use a local preview URL as a shareable delivery URL.

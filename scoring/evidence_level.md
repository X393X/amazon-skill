# Evidence Level

Use these levels:

- `A_live_market_data`: live Sorftime MCP or equivalent local private data with usable fields
- `B_provider_aggregate`: provider aggregate data without raw-level detail
- `C_public_safe_template`: anonymized or public-safe fixture sample
- `D_assumption`: inference or placeholder requiring validation

Every major claim must include conclusion, evidence, source, confidence, assumption, and missing data.

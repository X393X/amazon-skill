# amazon-skill

This repository publishes the `amazon-universal-listing-visual-skill` for Codex.

## Install

Run the installer and restart Codex after it finishes:

```bash
python ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py --repo X393X/amazon-skill --path amazon-universal-listing-visual-skill
```

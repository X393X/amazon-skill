# 亚马逊全品类 Listing / 视觉全案 / A+ 生成 Skill

## Skill 目标
将用户提供的任意亚马逊实体商品信息，按照固定顺序转化为一套可直接执行的完整方案：

1. 产品属性抽取
2. 类目调研与关键词体系
3. Listing 生成
4. 产品视觉全案策略
5. 图片体系规划
6. A+ 页面规划
7. 摄影执行建议
8. AI 出图方案 / 提示词
9. 最终输出《产品视觉全案策划方案》

本 Skill 默认服务以下角色与目标：
- 亚马逊卖家
- 电商运营负责人
- 转化优化负责人
- 品牌视觉决策者
- 摄影/设计执行人员
- AI 出图执行人员

默认优先级：
1. 搜索覆盖
2. 点击率
3. 转化率
4. 用户理解效率
5. 页面信任感
6. 差异化认知
7. 团队执行效率

## 强制执行原则

### 一、流程顺序不可打乱
始终遵循：
- 先策略、再视觉、后执行
- 先调研与词库、再 Listing、再全案、再图片、再 A+
- 先判断用户为什么买，再判断怎么搜，再判断怎么写，再判断画面怎么做

固定工作流：
1. 产品属性抽取
2. 信息缺口判断
3. 类目调研与关键词体系整理
4. Listing 生成
5. 视觉策略与图片体系规划
6. A+ 页面规划
7. 摄影执行建议
8. AI 出图方案
9. 最终整合输出

### 二、产品属性抽取必须前置
在生成任何内容之前，必须先提取产品核心属性。

至少包含：
- 产品类型
- 材质
- 结构
- 功能
- 使用场景
- 人群
- 风格
- 季节
- 颜色与外观特征
- 特殊工艺或设计点
- 尺码/规格/容量/尺寸（如适用）
- 合规可说边界
- 待确认项

硬性规则：
1. 不允许编造信息
2. 无法确认的内容标注“待确认”
3. 后续所有内容必须基于已抽取属性展开
4. 若信息不足以支撑某项判断，必须明确指出，不自行补齐
5. 竞品信息只能用于判断市场表达与差异化，不可直接当成本品事实

### 三、输出必须建立在“用户购买逻辑”上
所有内容必须回答四个问题：
1. 用户为什么买这个产品
2. 用户会怎么搜索这个产品
3. 我们应该怎么写才能提升搜索与转化
4. 画面该怎么做才能提升点击、理解与信任

### 四、默认适用范围
本 Skill 默认适用于亚马逊大多数实体商品，包括但不限于：
- 鞋服箱包
- 家居用品
- 户外用品
- 宠物用品
- 母婴用品
- 工具类产品
- 消费品

若为高合规/高风险类目（如医疗、保健品、电子电器、儿童用品、功效型产品等），必须额外提高以下约束：
- 不夸大功能
- 不写无法证明的性能
- 不写绝对化/保证性表述
- 不将竞品宣传语直接移植
- 不将推测性人群/场景写成本品事实

## 输入要求
当用户提供资料时，优先整理为以下输入块：

### A. 产品事实输入
- 产品名称
- 产品类型
- 品牌
- 站点/国家
- 材质
- 结构
- 功能
- 适用人群
- 使用场景
- 风格定位
- 季节属性
- 颜色/规格/变体
- 尺码/尺寸/容量/参数
- 特殊设计点
- 已知卖点
- 明确不能说的点
- 目标价格带
- 已有视觉素材情况

### B. 市场与竞品输入
- 核心竞品 ASIN / 链接
- 竞品标题/五点/A+
- Review / QA
- ABA/搜索词/广告出单词
- 前台联想词 / Related Searches
- Rufus/AI 购物助手真实问句（如有）

### C. 执行目标输入
- 本次核心目标：提升搜索 / 提升点击 / 提升转化 / 提升视觉执行效率 / 减少退货 / 新品冷启动 / 老品重做
- 输出语言
- 是否要图片文案
- 是否要 A+
- 是否要 AI 出图提示词
- 是否要摄影执行建议

如果用户输入不完整，也可以继续工作，但必须先输出《产品属性抽取卡》与《待确认项》再继续。

## 标准执行步骤

## Step 1：产品属性抽取
先输出《产品属性抽取卡》。

格式必须清晰列出：
- 已确认事实
- 待确认信息
- 合规边界

不允许在这一步夹带 Listing 文案。

## Step 2：类目调研与关键词体系
目标不是收集一堆关键词，而是建立“词—意图—落点”系统。

至少产出四项：
1. 本品事实表
2. 竞品共性与缺口表
3. 关键词分层表
4. 用户购买动机矩阵

### 关键词必须分层
至少拆为：
- 核心产品词
- 属性词
- 功能词
- 材质词
- 结构词
- 场景词
- 人群词
- 风格词
- 季节词
- 长尾问题词
- 限制条件词

### 每个关键词都要判断
- 用户为什么搜
- 当前处于什么决策阶段
- 转化价值高低
- 更适合放在哪个内容位置

不要只看搜索量。要同时看：
- 产品匹配度
- 购买意图强弱
- 竞争强度
- 内容适配性
- 转化价值

## Step 3：Listing 生成
按以下顺序生成：
1. 主标题
2. 副标题
3. 五点描述
4. Product Description
5. Search Terms
6. FAQ / QA 建议题库（如适用）

### Listing 生成要求
- 标题负责索引与相关性建立
- 五点负责理解与转化推动
- Description 负责语义补全与补充说明
- Search Terms 负责补充覆盖，不做前台重复堆砌
- FAQ / QA 负责补齐真实决策问题

### 标题原则
- 优先放硬信息：产品词、核心结构、核心功能、人群/场景限定词
- 不写空泛夸张形容词
- 不把所有信息塞进标题
- 不重复堆词

### 五点原则
每条都应包含：
- 卖点结论
- 结构/材质/参数依据
- 使用场景
- 用户感知结果

### Description 原则
建议写成：
1. 场景导入
2. 产品结构与功能说明
3. 规格/使用边界/适配说明
4. FAQ 式补充说明

## Step 4：产品视觉全案策略
视觉层面必须先回答：
1. 用户为什么买
2. 用户看到什么会点击
3. 用户看到哪些证据会信
4. 用户在哪一步会犹豫

至少输出：
- 核心视觉方向
- 主要购买场景
- 关键证据表达路径
- 决策消除策略
- 页面任务拆解

## Step 5：图片体系规划
按“1 主图 + 多张副图”的思路规划。

每张图都必须定义：
- 图号
- 核心任务
- 主卖点
- 画面形式
- 文字内容建议
- 必须展示的结构/细节
- 禁止事项

默认建议拆为：
1. 主图：点击位
2. 场景主卖点图
3. 结构证明图
4. 功能证明图
5. 材质/工艺图
6. 场景扩展图
7. 决策消除图

注意：
- 一张图只解决一个主问题
- 不允许画面职责混乱
- 文案必须放安全区
- 图文关系必须服务理解与转化

## Step 6：A+ 页面规划
A+ 不是堆词区域，而是完整上下文表达区。

至少规划：
- Hero 模块
- 核心卖点总览模块
- 结构 / Proof 模块
- 场景矩阵模块
- 材质 / 颜色 / 规格模块
- 决策消除模块

每个模块都要写清楚：
- 模块任务
- 文案主题
- 视觉形式
- 主要承载的信息

## Step 7：摄影执行建议
如果用户需要摄影执行方案，必须输出：
- 必拍镜头清单
- 产品静物镜头
- 结构特写镜头
- 上手/上身/使用状态镜头
- 场景镜头
- 模特/道具/环境建议
- 拍摄验收标准

## Step 8：AI 出图方案 / 提示词
AI 出图必须遵守：
- 先锁定产品一致性
- 再定义场景
- 再定义构图
- 再定义单图任务
- 最后加负面约束

Prompt 建议结构：
1. Product Lock
2. Audience & Scene
3. Composition
4. Proof Focus
5. Style
6. Constraints
7. Negative Prompts

如果用户需要整页 A+ 提示词：
- 先出素材图提示词
- 再出整页排版提示词
- 不要直接跳到整页，除非用户明确要求

## Step 9：最终整合输出
最后统一整理为《产品视觉全案策划方案》。

必须至少包含以下章节：
1. 产品基础定义
2. 类目与竞品调研
3. 关键词体系
4. 用户购买动机矩阵
5. Listing 方案
6. 产品视觉全案策略
7. 图片体系规划
8. A+ 页面规划
9. 摄影执行建议
10. AI 出图方案
11. 待确认项与风险点
12. 上线前质检清单

---

## 默认输出风格要求
- 结构清晰
- 先给框架，再给内容
- 不做空泛总结
- 不做无依据升华
- 所有判断尽量回到：用户为什么买、如何搜索、如何理解、如何转化
- 对缺失信息保持诚实
- 能明确判断的直接判断；不能明确判断的标注“待确认”

## 触发条件与工作模式
当用户提出以下任一需求时，调用本 Skill：
- 写标题和五点
- 做 Listing 全案
- 做亚马逊详情页/A+规划
- 做图片规划
- 做摄影脚本
- 做 AI 出图提示词
- 做从调研到落地的一体化策划
- 做适合团队复用的产品营销文案与视觉方案

当用户只提供产品基础信息时：
- 自动进入标准流程
- 先补属性抽取与待确认项
- 再继续后续输出

当用户提供竞品和关键词时：
- 强化“类目调研与关键词体系”部分

当用户提供视觉参考图时：
- 强化“视觉策略、图片体系、摄影执行、AI 提示词”部分

---

## 不允许做的事
- 不得把未知信息写成已知事实
- 不得默认竞品卖点等于本品卖点
- 不得无视合规边界
- 不得只堆关键词、不解释用户意图
- 不得先做图再反推文案逻辑
- 不得把 A+ 当作纯 SEO 区
- 不得给出没有任务分工的图片规划
- 不得给出没有产品锁定块的 AI 提示词

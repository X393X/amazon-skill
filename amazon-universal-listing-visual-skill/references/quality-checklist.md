# 质检清单｜输出前逐项检查

## 一、属性抽取
- [ ] 是否先完成产品属性抽取卡
- [ ] 是否明确区分“已确认事实”和“待确认项”
- [ ] 是否存在编造属性
- [ ] 是否写明合规边界

## 二、类目调研与关键词体系
- [ ] 是否不是只堆关键词，而是建立了“词—意图—落点”系统
- [ ] 是否拆分了核心产品词、属性词、场景词、人群词、长尾问题词
- [ ] 是否分析了用户为什么搜，而不只是词本身
- [ ] 是否输出了竞品共性与缺口

## 三、Listing
- [ ] 标题是否优先表达硬信息
- [ ] 五点是否每条都含有“卖点结论 + 依据 + 场景 + 结果”
- [ ] Description 是否完成语义补全，而不是简单重复五点
- [ ] Search Terms 是否避免与前台高频重复堆砌
- [ ] 是否避免夸张、绝对化、无法证明的表达

## 四、视觉策略与图片体系
- [ ] 是否先定义用户为什么买、为什么点、为什么信、为什么犹豫
- [ ] 是否每张图只有一个主任务
- [ ] 是否明确每张图的卖点、构图和文案任务
- [ ] 是否考虑文案安全区
- [ ] 是否避免图文职责混乱

## 五、A+
- [ ] 是否把 A+ 当作上下文表达区，而不是堆词区
- [ ] 是否有 Hero、Proof、场景矩阵、决策消除等模块
- [ ] 是否每个模块都有明确任务

## 六、摄影与 AI 出图
- [ ] 是否给出镜头任务单
- [ ] 是否给出产品锁定块
- [ ] 是否给出负面约束
- [ ] 是否先素材图后整页图

## 七、整体输出
- [ ] 是否遵循“先策略、再视觉、后执行”
- [ ] 是否遵循“先调研与词库、再 Listing、再全案、再图片、再 A+”
- [ ] 是否所有判断都能回到“为什么买、怎么搜、怎么写、怎么做画面”
